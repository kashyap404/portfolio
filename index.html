BlazeScript

A programming language with its frontend written from scratch in C++ and its backend powered by LLVM. It started as a project in building a toolchain end to end, covering the lexer, parser, and AST, semantic analysis.... The focus is now shifting toward using it as a compact hardware representation for LLMs. See the now section for details.

c++ · llvm · custom syntax

$ cat now.txt

Verilog is too low-level and un-structured for both humans and LLM agents to reason about efficiently. Blazescript would become a control-flow-preserving hardware representation (like Calyx's approach) that an LLM can read in far fewer tokens than raw RTL, while still compiling down to real Verilog via existing infrastructure like CIRCT/MLIR.
